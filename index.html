📖 Agent-Based Modeling Theory

1. What Are Agents?

An agent is an autonomous entity with its own properties (health, speed, position) and behavioral rules. Each agent perceives its local environment, makes independent decisions, and acts accordingly. In this simulation:

  • Survivors — Have health, stamina, fear level, infection status. They seek resources, flee zombies, navigate to safe zones.
  • Zombies — Pursue nearby survivors using detection radius. Chase and attempt infection on contact.
  • Police — Patrol areas, detect threats, engage zombies with limited ammunition.
  • Doctors — Move between injured survivors and hospitals. Provide medical aid with limited supplies.

2. Environment & Spatial Layout

The simulation world is a 2D city grid containing buildings (impassable), roads, parks, hospitals, police stations, supply depots, and safe zones. Agents navigate around obstacles and interact with the environment — safe zones reduce infection risk, hospitals enable healing, and supply locations provide resources.

3. Behavioral Rules

  • Survivor: IF zombie nearby → flee. IF health low → seek hospital. IF supplies needed → seek depot. IF safe zone nearby → move toward it. ELSE → wander.
  • Zombie: IF survivor in detection range → chase. IF contact → attempt infection (probability). ELSE → random wander.
  • Police: IF zombie in range AND ammo > 0 → engage. IF survivor in danger → protect. ELSE → patrol.
  • Doctor: IF injured survivor nearby → heal. IF infected AND cure enabled → cure. ELSE → move toward hospital.

4. Agent-to-Agent & Agent-to-Environment Interactions

Agent-to-Agent: Zombie→Survivor contact triggers probabilistic infection. Police→Zombie engagement eliminates threat. Doctor→Survivor interaction restores health.

Agent-to-Environment: Safe zones reduce infection probability by 80%. Buildings block movement. Hospitals enable healing. Supply depots replenish resources.

5. State Transitions

Survivors: Healthy → Infected → (Zombie | Dead). Infection has a delay period (~300–600 ticks). During this window, doctors can potentially save the survivor. The cure system (when enabled) allows limited doses.

6. Emergent Behavior

Complex global patterns emerge from simple local rules. No single agent controls the outcome:

  • A small outbreak can cascade exponentially if survivors cluster.
  • Strategic police placement creates containment perimeters.
  • Safe zones can become overwhelmed if too many survivors converge.
  • Resource scarcity forces trade-offs between fleeing and gathering.

Example: With 5 zombies, 60 survivors, and no police, infection spreads rapidly. Add 10 police, and the same scenario may result in full containment — demonstrating how a single parameter produces dramatically different emergent outcomes.

7. Simulation Time Steps

The simulation advances in discrete ticks (~60/sec at 1x). Each tick: (1) agents perceive surroundings, (2) evaluate rules, (3) execute movement, (4) apply state transitions, (5) collect statistics. Fixed random seeds enable reproducible experiments.

⚗️ Experiment Comparison Mode

Run two simulations with different parameters and compare outcomes side by side. Each experiment runs for 1500 ticks (~25 seconds).
